## 🚀 What's New in v4.3.0

### 1. Shadowing Mode ('Shadow the Fox')
- PracticeScreen simultaneous speaking practice with animated 3-2-1 countdown, mic auto-trigger, and configurable delay settings (0/250/500ms).

### 2. Offline Content Pack
- 5 pre-built raw JSON sessions (animals, colors, family, food, school) managed via OfflineContentStore, zero-latency fallback when network or API is unavailable.

### 3. Intermediate 'Challenge Track' (Level 2+)
- B1-level vocabulary and longer sentence challenges triggered for Level C children with 30+ completed sessions.

### 4. 5 New Curated Roleplay Scenarios
- Doctor's Office, Supermarket, Birthday Party, Library Visit, Weather Talk added to RoleplayScenarioBank.

### 5. CEFR Level Indicator
- Pure function CefrMapper mapping GradeBand + DiagnosticLevel to CEFR (Pre-A1 to B1), displayed on Dashboard and WeeklyReportScreen.

### 6. Printable English Growth Report Card
- ReportCardScreen generating A4 (1240×1754) PNG report cards with CEFR level, stats grid, top words, and LLM teacher comment for sharing.
