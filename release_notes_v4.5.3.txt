## 🛠️ Lingo English v4.5.3 — Voice Check & Loading Experience Fix Pack

### 1. Voice Check No Longer Hangs
- The ASR WebSocket transcription had no overall deadline (only a 20s ping interval), so a dead or half-open connection could leave the child stuck in the "evaluating" state indefinitely. A 30-second overall timeout now bounds every voice-check round-trip.

### 2. Voice Check Errors Tell You Why
- When a voice check fails, the message now distinguishes the actual cause instead of one generic line:
  - Wrong API key / auth → "check your API key in Settings"
  - Not configured → "check the ASR settings"
  - Timeout → "the voice check timed out"
  - Network drop → "check your connection"
  - Server error → a clear retryable message
- No fake scores: the app still never fabricates a pronunciation result — it surfaces the real failure so the child can retry.

### 3. Quiz Loading Shows Progress
- The diagnostic quiz ("Lingo is preparing your quiz…") legitimately takes 20-40s because it's real AI generation. It now rotates staged status messages ("Talking to Lingo's teacher… / Picking words just for you… / Writing your questions… / Almost ready…") so it communicates progress instead of looking like a hang.

### Verification
- Full unit test suite green: 422 tests, 0 failures. Debug APK builds clean.
